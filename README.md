CarbonTrack

A web-based carbon emission tracking application built with Java Spring Boot, Thymeleaf, JPA, and PostgreSQL.

Features
User registration and login
Carbon emission tracking
Carbon budget management
Dashboard and emission insights
Daily challenges
Rewards and points
Leaderboard
Travel planner
PDF report generation
Tech Stack
Java 21
Spring Boot 3.3.2
Spring MVC
Spring Data JPA
Thymeleaf
PostgreSQL
Maven
Lombok
iTextPDF
